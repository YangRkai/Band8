# Changelog

## 0.1.0-alpha.1

### Added

- B8TP 0.1 validation, RFC 8785 package identity, and an append-only Runtime evidence kernel.
- Reading protected evaluation, package idempotency, and crash/restart recovery.
- Writing artifacts with External Coach checkpoint, portable bundle, and continuation validation.
- Evidence-driven mission, retention, transfer, pattern, reveal, and effective-learning-day projections.
- IANA learning timezones with immutable timezone epochs.
- A loopback React/Vite product shell for Today, Train, Progress, History, Coach, and Settings.

### Security and release hardening

- Loopback-only HTTP transport with origin and startup-session mutation protection, bounded payloads, inert text rendering, and learner-safe DTOs.
- Load-time identity revalidation for accepted packages and protected evaluation, with session quarantine on integrity failure.
- TypeScript `TEXT_RESPONSE` import validation aligned with the frozen Python protocol oracle.
- Apache-2.0 licensing, public documentation, reproducible dependency declarations, verification-only CI, and clean-clone release gates.

This alpha does not provide automatic coaching, calibrated IELTS score estimation, Speaking/audio, cloud sync, or public-server operation.

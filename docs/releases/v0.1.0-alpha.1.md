# Band8 v0.1.0-alpha.1

## What this alpha proves

Band8 can keep an external AI Coach outside the authoritative learning Runtime while still delivering a usable local Reading and Writing loop. Packages cross a versioned protocol boundary; the Runtime validates and executes them, records immutable evidence and artifacts, and projects reinforcement from validated progress.

## Included

- B8TP 0.1, RFC 8785 identity, strict package import, and protected evaluation;
- append-only evidence, idempotent imports, recovery, and exactly-once reinforcement;
- Reading activities and Writing artifact/checkpoint/continuation flows;
- mission, retention, transfer, pattern, reveal, and learning-timezone projections;
- loopback Local Web Shell with Today, Train, Progress, History, and Coach;
- synthetic public fixtures, reproducible tests, and Windows/Linux clean-clone verification plumbing.

Accepted package and protected-evaluation content is revalidated against its Runtime-owned identity when loaded. Integrity failures isolate the affected session instead of allowing changed bytes to influence authoritative results. TypeScript import validation for `TEXT_RESPONSE` also matches the frozen Python oracle's kinds and character bounds.

## Known limitations

Speaking/audio, transcription, automatic Coach integration, calibrated IELTS scoring, cloud sync, native mobile packaging, Electron/Tauri, and a browser-only PWA Runtime are not included. A Coach assessment is inference, not an official IELTS result. No outcome or exam score is guaranteed.

## Security and data model

The browser is a presentation layer. The Node.js Runtime remains authority for sessions, evidence, artifacts, protected evaluation, missions, timezone epochs, and reinforcement. The server is loopback-only and is not supported for LAN or Internet exposure. No analytics or telemetry service is present. Learning data remains local unless the user explicitly exports a Coach bundle.

See [Security Policy](../../SECURITY.md), [Trust Boundaries](../architecture/TRUST_BOUNDARIES.md), and [Content Provenance](../CONTENT_PROVENANCE.md).

## How to try it

Follow the clean-clone [Quick Start](../QUICKSTART.md). It installs pinned dependencies, runs protocol and Runtime verification, imports a generated Reading package, and starts the local Web Shell.

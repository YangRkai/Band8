# 默认中文 README 设计

## 目标

让 GitHub 仓库首页默认展示完整中文 README，同时保留内容等价的英文入口，降低中文用户理解和本地启动 Band8 的门槛。

## 方案

- `README.md` 改为中文版，顶部语言顺序为“简体中文 | English”。
- 新建 `README.en.md`，保存当前英文内容，顶部提供返回中文版的入口。
- 中文版忠实覆盖当前英文版中的项目定位、架构、现有能力、快速开始、External Coach、证据与强化、限制、安全、开发、路线图、许可证及商标声明。

## 边界

- 不修改 B8TP、Runtime、产品功能、命令或版本号。
- 不增加未经证据支持的 IELTS 分数承诺或产品能力。
- 不改动现有未跟踪文档。
- 通过 release 文档测试固定默认中文入口和双向语言链接。

## 已选方案

采用“中文作为默认 `README.md`、英文迁移至 `README.en.md`”的方案。相比仅新增中文链接，它确保 GitHub 首页首先展示中文；相比删除英文，它保留国际协作者入口。
